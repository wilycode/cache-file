# Changelog

All notable changes to **WilyCode File Cache** will be documented here.

## [0.1.0] - 2026-10-12

### Added

- Initial public release of a PSR-16 file-based cache for PHP 8.4+.
- Hashed cache-file paths and atomic file writes.
- Integer and `DateInterval` TTL handling.
- Single-key and bulk cache operations.
- Expired and invalid cache-entry cleanup on read.
- Automated tests via GitHub Actions.
